# API / 서버 동작

> 1단계에서는 아직 API 가 없습니다. 2단계부터 채워집니다.

## 설계 원칙

- 데이터 변경(생성/수정/삭제)은 **Next.js Server Actions** 또는 **API
  Route** 에서만 수행한다.
- 모든 변경에는 **서버 측 권한 검사**를 둔다. (UI 숨김만으로는 불충분)
- 예산·합계 계산은 클라이언트가 아니라 서버의 `lib/budget/*` 에서 한다.
- Slack 발송 등 비밀값을 쓰는 호출은 서버에서만 실행한다.

## (예정) 주요 엔드포인트

| 영역 | 동작 |
| --- | --- |
| 예산 | 스냅샷 생성, 지원금 재계산, 거래 CRUD, CSV 업로드 |
| 출결 | 모임 생성, 참여 응답, QR 세션 발급, 체크인, 수동 보정 |
| 활동 | 활동 CRUD, 거래 연결, 사진 업로드/선택 |
| 보고서 | 월간 예산 보고서, 활동 보고서 생성 + export |
| 알림 | Slack 테스트 발송, 이벤트 알림 |
