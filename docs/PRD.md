# 모임 서비스 PRD v1

## 1. 제품 정의

모임은 회사 내부 동호회의 지원금, 법인카드 사용, 출결, 활동 사진, 활동
보고서를 한 흐름으로 관리하는 웹앱입니다.

## 2. 1차 타깃

회사 내부 동호회. (외부 계모임/친목 모임/복잡한 회비 정산은 MVP 제외)

## 3. 핵심 우선순위

1. 활동 금액 쉽게 트래킹
2. QR 출결 자동화
3. 활동 보고서 생성
4. 공지/FAQ 는 후순위

## 4. 예산 정책

- 매월 15일 기준 활동 회원 수를 스냅샷으로 저장한다.
- 월 지원금 = 매월 15일 기준 활동 회원 수 × 50,000원.
- 미사용 예산은 반기 안에서만 이월된다. (반기: 1~6월 / 7~12월)
- 반기 종료 시점에 남은 예산은 소멸된다.
- 결제는 회장 또는 총무에게 부여된 기명 법인카드로 한다.
- 카드 사용 내역을 활동과 연결한다.
- 예산 내역은 회원 전체에게 공개하되 카드번호·승인번호 전체 등 민감정보는
  마스킹한다.

## 5. 사용자 역할

- **Owner**: 동호회 생성/삭제, 역할 부여, 전체 설정
- **President(회장)**: 모임 생성, 출결 관리, 활동 이야기 작성/검수, 보고서
- **Treasurer(총무)**: 카드 사용 내역 입력/CSV 업로드/영수증 첨부, 예산 보고서
- **Member(회원)**: 모임 참여 응답, QR 체크인, 사진 업로드, 예산 내역 열람

## 6. 보고서

- **월간 예산 보고서**: 카드 사용자, 사용일, 사용금액, 가맹점, 연결 활동,
  월간 총 사용금액, 반기 누적 사용금액, 반기 잔여 예산. (Excel/CSV)
- **활동이야기 보고서**: 활동명, 활동일, 장소, 참석자 수, 사진, 활동 내용,
  연결 사용 내역, 사용금액 합계. (PDF/인쇄용)

## 7. MVP 제외

카드사 API 직접 연동, SMS 자동 읽기, 위치 기반 출석, 지각/조퇴, 카카오
알림톡, 복잡한 결재 승인, FAQ 봇.
