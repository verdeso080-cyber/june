# 구현 로드맵

작은 단계로 나눠서 진행하며, **각 단계마다 lint/typecheck/test/build 4종
검증을 통과**시킨 뒤 다음 단계로 넘어간다.

| 단계 | 내용 | 상태 |
| --- | --- | --- |
| 1 | 프로젝트 토대 (Next.js·TS·Tailwind·Prisma·ESLint·Vitest + 검증 스크립트) | ✅ 완료 |
| 2 | 데이터 모델(Prisma) + 예산 엔진(반기/스냅샷/지원금/잔여/소멸) + 테스트 | ⏳ |
| 3 | 예산 대시보드 / 카드 사용 내역(수기·CSV) / 마스킹 공개 | ⏳ |
| 4 | 모임 / QR 출결 / 활동 이야기(사진·거래 연결) | ⏳ |
| 5 | 보고서(월간 예산=Excel·CSV / 활동이야기=PDF) | ⏳ |
| 6 | Slack webhook 알림 | ⏳ |
| 7 | 인증/초대코드/권한 강화(서버 강제) | ⏳ |
| 8 | 전체 자기검증(QA) + 배포 준비 | ⏳ |
| 9 | 공지/FAQ (후순위) | ⏳ |

## 확정된 결정사항

- 기존 무관 앱(은영스쿨)은 `legacy/aistudio-app/` 에 보관(삭제 아님).
- "활동 회원 수" = 현재 `ACTIVE` 상태 회원 수.
- 보고서 export: 예산/숫자 = Excel, 활동이야기 = PDF.
